愛發筆輸入法

下載

三種下載：字根表 PDF（列印或離線查閱用）、macOS 輸入法安裝包（鼠鬚管）、iOS 輸入法安裝包（仓／Hamster）。安裝包裡的碼表跟這個網站、跟這個 repo 目前的版本一致，不是另外維護的舊版本。

1. 字根表 PDF

整張〈字根表〉排成 A4，可以列印或存起來離線查閱。內容跟網頁上看到的一模一樣，包括每個字根在例字裡高亮哪幾筆的圖——不是另外做的簡化版。

2. macOS 安裝包

給用鼠鬚管（Squirrel）的 macOS。安裝包只有碼表跟設定檔，鼠鬚管本身要先另外裝好。

  1. 還沒裝鼠鬚管的話，先到Rime 官網下載，或用 brew install --cask squirrel。
  2. 下載安裝包，解壓縮。
  3. 把解壓出來的所有檔案（包括整個 lua 資料夾）複製到 ~/Library/Rime/——這個資料夾原本就有東西的話，直接放進去合併就好，不用清空。
  4. 點選單列的鼠鬚管圖示 →〈重新部署〉。
  5. 系統設定 → 鍵盤 → 輸入法來源，加入「鼠鬚管」，切到「愛發筆」。

3. iOS 安裝包（仓／Hamster）

給 iOS 的「仓輸入法」（App Store 搜「仓」，開發者 imfuxiao）。這個安裝包另外附了一份鍵盤佈局：萬用鍵獨立成一顆真的鍵（Q 正下方、A 左邊），符號鍵也換成一頁排滿的數字符號表，不是「仓」原生那種要先選類別的清單。整個過程都在手機上完成，不需要電腦。

  1. 下載安裝包，存到手機的「檔案」App。
  2. 在「檔案」App 長按這個 zip →〈分享〉→「仓」（會自動解壓到 Rime 目錄）；或在「仓」內「輸入方案設置」→ 右上角「+」→「導入方案」選這個 zip。
  3. 到「仓」的「RIME」頁籤，按〈重新部署〉——這一步一定要做，且要在「RIME」頁籤裡直接按，不能只靠匯入方案那一步順便觸發，不然鍵盤佈局不會生效。
  4. 「輸入方案設置」裡確認「愛發筆」已勾選。
  5. 「鍵盤設置」→「鍵盤佈局」，選「自訂-愛發筆26鍵」。

這個安裝包還多定義了兩顆鍵盤（供符號鍵切換用），也會各自出現在「鍵盤佈局」清單裡——這是「仓」的正常行為，不要選它們、也不要刪它們，刪掉會連帶讓整組自訂鍵盤從清單消失。

下載 iOS 安裝包

目前只準備了 iOS 的鍵盤佈局；Android 還沒有對應的安裝包。Windows（小狼毫）、Linux（ibus/fcitx5-rime）也能用同一份碼表，只是沒有另外包成 zip——把 macOS 安裝包裡的檔案（不含 squirrel.custom.yaml）丟進對應平台的使用者目錄即可。
