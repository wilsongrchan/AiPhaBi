# 〈字根練習〉要考哪幾題 —— 手挑

> **這一頁是「歡迎模式」**：首頁直接連過來的三關入門，題目是手挑的一小批
> （Wilson 2026-09-01）。將來可能再做一個「完整模式」，把整張字根表都練過一遍 ——
> 那會是另一個進入點，不是把這裡的題目加到幾百題。這一頁刻意保持短。

練習頁一次問一條字根：把它在某個字裡的筆畫標出來，問它像哪個英文字母。
**用哪個字、考它的哪幾條字根，全部由這個檔決定。**

改完跑一次就生效：

```bash
python3 site/tools/build_site_data.py
python3 site/tools/preview.py
```

---

## 格式

一行一個字：

```
字 = 字母 字母 …
```

意思是「拿這個字出題，考它的這幾條字根」。字母用空格隔開，順序不影響。
`#` 開頭的行和空行會被忽略。

字母後面可以再加一個 `·` 和一句**提示**。提示會原封不動接上「，像哪個字母？」
變成題目那一句話，所以它要寫成一個完整的說法：

```
檢 = A O                         →  「這個字根像哪個字母？」
雪 = E · 旋轉或翻轉這個字根後     →  「旋轉或翻轉這個字根後，像哪個字母？」
北 = F · 把這個字根旋轉 180 度後  →  「把這個字根旋轉 180 度後，像哪個字母？」
```

要轉、要翻才看得出來的字根**一定要寫**提示 —— 不先講一聲，那題就不是在考眼力
而是在考通靈。寫了提示的題目，畫面上還會多一排「順轉 90°／逆轉 90°／上下翻轉／左右翻轉／還原」，
可以真的把字根轉過來看。

例如 `檢 = A O`：檢 拆成 `T A O O Y Y` 六段，這樣寫就只考 A 那一段和 O 那一段，
木（T）和末尾兩個 Y 不會被問到。

同一個字母在一個字裡出現好幾次時，預設標**第一處**。要指定是哪一處就寫
`字母:序號`，1 起算，負數從後面數：

```
慧 = E:3    慧 拆成 E E E W，這是 W 前面那個 E（也可以寫 E:-1）
```

同一個字母在一個字裡出現好幾次（檢 的兩個 O、巡 的三個 L）算**同一題**，
而且只標**第一處** —— 分成兩題等於連著問兩次一樣的問題，幾處一起標又會讓人
不知道該看哪一塊。

## 關卡

**`## 分組 · 名稱` 一組就是一關**，順序照這個檔。練習頁一次只出一關的題，那一關
全部答對過（或至少看過答案）之後才進到下一關，也可以按「下一關」直接跳過去；
一關十題全部答對還會問你要下一關還是再練這一關。

關卡只有編號，沒有名字（畫面上就是「第一關　8／10」）—— 一題該怎麼看是那一題
自己的提示在講（見上面的 `·`），分組的名稱不會出現在網站上。

⚠️ **答對八題就過關**，一關可以放**更多題** —— 多出來的是備胎，不喜歡的題目
可以按「跳過」，還有別的可以練。少於八題那一關永遠過不了，建置會出聲。

## 建置時會檢查

- 那個字還沒取碼 → 出聲，那一行跳過
- 寫的字母不在那個字的拆碼裡（例如 `去 = X`）→ 出聲並印出它實際拆成什麼
- 那個字沒有字形資料（畫不出筆畫）→ 出聲，那一題不出
- 同一個字寫了不只一次 → 出聲，只有第一行算數
