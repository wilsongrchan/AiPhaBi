# 〈字根練習〉要考哪幾題 —— 手挑

練習頁一次問一條字根：把它在某個字裡的筆畫標出來，問它像哪個英文字母。
**用哪個字、考它的哪幾條字根，全部由這個檔決定。**

改完跑一次就生效：

```bash
python3 site/tools/build_site_data.py
python3 site/tools/preview.py
```

---

## 格式

一行一個字：

```
字 = 字母 字母 …
```

意思是「拿這個字出題，考它的這幾條字根」。字母用空格隔開，順序不影響。
`#` 開頭的行和空行會被忽略。

字母後面可以再加一個 `·` 和一句**提示**，它會被寫成題目那一句話：

```
雪 = E · 水平翻轉      →  「將這個字根水平翻轉，像哪個英文字母？」
巡 = L · 稍微旋轉      →  「將這個字根稍微旋轉，像哪個英文字母？」
```

沒寫提示就是預設的「標出來的這一條字根，像哪個英文字母？」。要轉、要翻才看得出來
的字根一定要寫 —— 不先講一聲，那題就不是在考眼力而是在考通靈。

例如 `檢 = A O`：檢 拆成 `T A O O Y Y` 六段，這樣寫就只考 A 那一段和 O 那兩段，
木（T）和末尾兩個 Y 不會被問到。

同一個字母在一個字裡出現好幾次（檢 的兩個 O、巡 的三個 L）算**同一題**，
而且只標**第一處** —— 分成兩題等於連著問兩次一樣的問題，幾處一起標又會讓人
不知道該看哪一塊。

## 關卡

`## 關卡 · 名稱` 開一個新的關卡，底下的題目都屬於它。練習頁一次只出一個關卡的題，
那一關的題目全部答對過（或至少看過答案）之後才會進到下一關，關卡名稱會顯示在題目
上方 —— 所以名稱要寫成「看到它就知道這一關在練什麼」，第二關的名稱本身就是提示。

⚠️ 只有**開頭是「關卡」**的 `##` 標題算數（這份說明自己的小標題不會被誤認）。
第一個關卡標題之前的題目算第一關。

## 建置時會檢查

- 那個字還沒取碼 → 出聲，那一行跳過
- 寫的字母不在那個字的拆碼裡（例如 `去 = X`）→ 出聲並印出它實際拆成什麼
- 那個字沒有字形資料（畫不出筆畫）→ 出聲，那一題不出
- 同一個字寫了不只一次 → 出聲，只有第一行算數
