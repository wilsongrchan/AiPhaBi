# 字根表的例字 —— 手挑

**這個檔只管〈字根表〉那張大表**（每個字母底下「字根｜字例｜取形意圖」的那張）。
〈相近字形辨析〉的例字不在這裡，那一節整節都由 `similar.md` 決定，改這個檔不會動到它。

字根表每一列的例字，預設是**照字頻自動挑前 4 個**。這個檔是用來覆蓋的：
列在這裡的字根就用你指定的字，沒列到的照舊自動挑。

改完跑一次就生效：

```bash
python3 site/tools/build_site_data.py
python3 site/tools/preview.py
```

---

## 格式

一行一個字根：

```
字母 來源字 = 例字 例字 例字
```

- **來源字**就是字根表「字根」欄裡那個小小的灰字（字根取自哪個字）。
- 例字用空格隔開，要幾個都可以（不限 4 個）。
- `#` 開頭的行和空行會被忽略。

同一個字母底下如果有兩個字根取自**同一個來源字**，光寫來源字不夠，要再加筆序：

```
字母 來源字#筆序 = 例字 例字
```

目前只有四個字根需要這樣寫：`F 學`、`K 鼎`、`P 們`、`R 所`。
其餘 410 個字根寫「字母 來源字」就夠了。筆序從 1 開始，用逗號分隔，
跟字根表上顯示的「第 1–3 筆」一致（範圍要逐一列出，例如 `1,2,3`）。

## 建置時會檢查

跑 `build_site_data.py` 時會逐條驗證，有問題會印出來（但不會中斷建置）：

- **找不到這個字根** —— 字母或來源字寫錯，或那個字根被 Side A 合併掉了。
- **例字沒有用到這個字根** —— 這是最重要的一條。程式會去 `codes.json` 查那個字的
  拆碼，確認裡面真的有一段是這個字母、而且筆數對得上。查不到就表示這個字舉錯了，
  它會照樣顯示但**不會高亮**（因為根本不知道要塗哪幾筆）。
- **來源字有歧義** —— 上面說的那四個，沒寫筆序就會提醒。
