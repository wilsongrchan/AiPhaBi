# 取形意圖的額外說明 —— Wilson 手寫

大多數字根一看就知道為什麼像那個字母，不需要解釋。少數需要多講一句
（為什麼這一類形狀算是像 A、像 E），寫在這裡，會顯示在〈字根表〉該取形意圖的說明底下。

改完跑一次就生效：

```bash
python3 site/tools/build_site_data.py
python3 site/tools/preview.py
```

---

## 格式

一行一條，`字母＋序號 = 說明`：

```
A3 = 形近 A 字兩條直線夾住中間短橫。
```

序號是那個字母底下**取形意圖由上到下的順序**（A1、A2、A3…），跟字根表上看到的一致。

⚠️ 序號會隨 Side A 合併或調整取形意圖而移動。所以建置時會把每一條對到的意圖
**原文印出來**，例如：

    intent_notes A3 → 「半包框中夾一點，包括類似"勺"…」

跑完看一眼那行對不對就好；對不上就是意圖的順序變了，改一下序號即可。
超出範圍（例如 A9）會直接警告。

# ↓↓↓ 寫在這裡 ↓↓↓

A3 = 形近 A 字兩條直線夾住中間短橫。
E3 = E 字亦是上下皆橫，而且一共只有三橫，所以此意圖收納的字根亦皆只有三橫（有些字根中一橫寫作一撇或一提）。
